\section{System Architecture}

AgriQueue follows a three-tier architecture:
\begin{itemize}
  \item \textbf{Tier 1 -- Presentation:} React 19 SPA hosted on Vercel CDN.
  \item \textbf{Tier 2 -- Application:} FastAPI ASGI server (Uvicorn) with ML module and AI agent.
  \item \textbf{Tier 3 -- Data:} PostgreSQL accessed via SQLAlchemy 2.0 async + asyncpg.
\end{itemize}

\section{Functional Modules}
\begin{itemize}
  \item \textbf{M1: Auth \& RBAC} -- JWT cookie login/logout, role guards on all endpoints.
  \item \textbf{M2: Centers \& Slots} -- Center discovery, slot capacity with expiry detection.
  \item \textbf{M3: Booking Engine} -- Capacity validation, token assignment, ML wait time call.
  \item \textbf{M4: Live Queue (SSE)} -- 5-second push stream; farmer position + wait estimate.
  \item \textbf{M5: ML Predictor} -- HistGBR model; 13 features; joblib artifact; heuristic fallback.
  \item \textbf{M6: Procurement} -- Staff weight/grade/rate entry; net payable computation.
  \item \textbf{M7: Payment Lifecycle} -- Scheduled $\to$ Processing $\to$ Settled; dispute management.
  \item \textbf{M8: Admin CRUD} -- Full management of centers, slots, produce, staff, users.
  \item \textbf{M9: Push Notifications} -- VAPID subscription store; push on queue/payment events.
  \item \textbf{M10: AI Agent} -- LangChain + LangGraph ReAct agent; Gemini backend; NL queries.
\end{itemize}
