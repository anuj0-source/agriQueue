\section{Test Strategy}
\begin{itemize}
  \item \textbf{Unit Testing:} Individual API functions tested with FastAPI \texttt{TestClient}.
  \item \textbf{Integration Testing:} React frontend connected to live backend with test PostgreSQL database.
  \item \textbf{System Testing:} Complete end-to-end workflow: Register $\to$ Book $\to$ Queue $\to$ Procurement $\to$ Payment.
  \item \textbf{ML Validation:} Model validated on 2,000-sample held-out test set (R\textsuperscript{2}, RMSE, MAE).
  \item \textbf{Security Testing:} JWT expiry, role guards, CORS, password hashing, XSS/CSRF prevention.
  \item \textbf{Performance Testing:} Concurrent SSE connections and concurrent booking API requests.
  \item \textbf{UAT:} Full walkthrough of all three portals by team members acting as end users.
\end{itemize}

\section{Performance Results}
\begin{itemize}
  \item \textbf{API response time:} Average 85ms (booking), 45ms (queue snapshot), 120ms (dashboard).
  \item \textbf{SSE concurrency:} 10 simultaneous connections -- no memory leak, no stale data.
  \item \textbf{Concurrent bookings:} 50 concurrent POST /bookings -- slot capacity correctly enforced.
  \item \textbf{Frontend load:} First Contentful Paint $<$ 1.2s on broadband (Vite production build).
\end{itemize}

\section{Security Test Results}
\begin{itemize}
  \item JWT tokens expire after 7 days -- expired tokens return 401.
  \item Farmer cannot access \texttt{/staff/*} or \texttt{/admin/*} -- returns 403.
  \item Passwords stored as Argon2id hash -- no plain text stored anywhere.
  \item HttpOnly + Secure + SameSite=None cookies prevent XSS and CSRF.
  \item SQLAlchemy ORM parameterized queries block all SQL injection attempts.
  \item CORS policy restricts requests to whitelisted origins only.
\end{itemize}
