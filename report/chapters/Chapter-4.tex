\section{Module Descriptions}
\begin{itemize}
  \item \textbf{Database \& ERD:} Designed 12 tables -- farmers, procurement\_centers, slots, bookings, procurement\_records, payments, payment\_profiles, staff, admins, produce, push\_subscriptions, agent\_audit.
  \item \textbf{Authentication:} JWT HttpOnly cookie login for 3 roles. Argon2id password hashing. Endpoints: login, register, /me, logout.
  \item \textbf{Centers \& Slots:} Center listing with search/filter. Slot availability with expiry detection. Capacity computation per slot per date.
  \item \textbf{Booking Engine:} Booking creation with slot capacity validation, token assignment, ML wait time call, and cancellation logic.
  \item \textbf{Queue (SSE):} SSE generator with 5-second fresh \texttt{AsyncSessionLocal} tick. Computes farmer position, tokens ahead, real-time wait estimate.
  \item \textbf{ML Model:} 10,000-record synthetic dataset. HistGradientBoosting with 13 features. R\textsuperscript{2}~=~0.988. Serialized via joblib.
  \item \textbf{Staff Portal:} Token calling, procurement record entry, payment lifecycle (Scheduled $\to$ Settled), dispute management. Largest module: \texttt{staff.py} (1012 lines).
  \item \textbf{Admin Portal:} Full CRUD for centers, slots, produce, staff, users. System-wide analytics.
  \item \textbf{Push + AI Agent:} VAPID WebPush for booking/payment events. LangChain + LangGraph ReAct agent with Gemini for NL queries.
\end{itemize}
